# Tigo

Приложение для запуска и подбора стратегий zapret на Windows.

## Требования

- Windows 10 или 11, x64
- права администратора

## Установка

1. Откройте [Releases](https://github.com/Factiosi/Tigo/releases/latest) и скачайте установщик `Tigo-Setup-*.exe`.
2. Запустите установщик.
3. Откройте Tigo через меню «Пуск».
4. Подтвердите запрос Windows на запуск от имени администратора.

При первом запуске Tigo сам скачает необходимые файлы Flowseal. После этого выберите стратегию на главном экране и нажмите «Запуск».

Для поиска подходящей стратегии откройте «Подбор стратегий», отметьте нужные варианты и запустите тест. Завершённые результаты сохраняются.

## Обновления

Проверка обновлений Tigo включена по умолчанию. Установка выполняется вручную через настройки. Стратегии и служебные файлы Flowseal обновляются отдельно.

## Данные

Настройки, стратегии, списки и результаты тестов находятся в `%APPDATA%\Tigo`.

## Ограничения

- установщик не подписан цифровой подписью, поэтому Windows может показать предупреждение.
