# Changelog

## 1.1.2

Минорные исправления интерфейса

## 1.1.1

- Исправлен запуск с выбранной стратегией: daemon перечитывает settings и принимает явный strategy_id.
- Исправлена смена стратегии при работающем zapret: select закрывается сразу, статус «перезапуск…».
- Исправлен crash кнопки «Выбрать стратегию» на странице подбора.
- Исправлено мигание спиннеров в live probe-таблице.
- Раскрытие результатов тестов ограничено стратегиями текущей сессии.

## 1.1.0

- Добавлен менеджер обновлений Tigo.
- Восстановлены полные и поэтапные результаты тестов стратегий.
- Добавлены статусы и быстрый выбор протестированных стратегий.
- Исправлены зависания интерфейса при массовом тестировании.
- Добавлены installer и автоматизация выпуска релизов.

## 1.0.0

- Windows daemon с tray и localhost IPC остаётся владельцем winws после закрытия GUI.
- Поддержаны Flowseal-стратегии, пользовательские списки, фильтры и обновление runtime.
- Добавлены стандартный подбор стратегий, кэш результатов и отдельная debug console.
- Подготовлены Nuitka standalone-сборка и installer Inno Setup без видимых консольных окон.

Ограничения: DPI-тест и code signing пока недоступны.
